# Simple Document Q&A - RAG

## Project Description

A document question-answering system that allows users to
upload a PDF or text document and ask questions based only
on the information contained in the document.

## Objective

To build a beginner-friendly Retrieval-Augmented Generation
(RAG) application using document processing, embeddings,
vector retrieval, and a Large Language Model.

## Team

- Member 1 - RAG and Retrieval
- Member 2 - Document Processing
- Member 3 - LLM, Backend and Frontend
